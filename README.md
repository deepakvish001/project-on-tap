# India Airfare Insights

Design and build the HOME / LANDING PAGE for a Government of India–oriented statistical platform called:

APIx — Real-time Airfare Price Index for India

The platform is being developed for the Ministry of Statistics and Programme Implementation (MoSPI) to monitor and analyse domestic airfare movements in India.

IMPORTANT DESIGN DIRECTION:

Do NOT copy the eSankhyiki website visually.

Take inspiration only from its philosophy:

- simple government portal structure

- clear information hierarchy

- easy navigation

- official and trustworthy appearance

- separate sections instead of putting everything on one page

- accessible to government officials, researchers and policymakers

- clean statistical presentation

The result should look like a realistic modern Government of India statistical portal, NOT a startup SaaS dashboard, NOT a fintech dashboard, and NOT a flashy AI website.

PAGE PURPOSE:

The Home page should introduce APIx, explain what the platform provides, and guide users toward different sections of the platform. Do not show every analytical chart or metric on the homepage.

HEADER:

Create a clean official government-style header.

Left side:

- Government of India emblem area

- Ministry of Statistics and Programme Implementation

- subtle "Data & Statistics" identity

Center/brand:

- APIx

- Real-time Airfare Price Index

Right side:

- English / हिन्दी language selector

- Light / Dark mode toggle

- Search icon

- accessibility option

Navigation:

- Home

- Airfare Index

- Explore Data

- Route Analytics

- Trends

- Backtesting

- CPI Benchmark

- Data Sources

- About APIx

Keep the navigation simple and professional.

HERO SECTION:

Create a restrained but visually strong hero section.

Heading:

"Real-time Airfare Price Index for India"

Supporting text:

"An analytical platform for monitoring domestic airfare movements using high-frequency airfare observations, route-level passenger traffic and official statistical benchmarks."

Primary button:

"Explore APIx"

Secondary button:

"Explore Data"

Use a subtle India/data/air-transport visual element in the background.

Avoid excessive gradients, glowing effects, 3D graphics or futuristic AI visuals.

INTRODUCTION SECTION:

Create a section titled:

"Understanding India's Airfare Movement"

Briefly explain:

- Airfares change dynamically with demand, route, booking time and other market factors.

- APIx is designed to provide a high-frequency view of these movements.

- The platform combines airfare observations with route-level statistical information.

- The resulting index can support monitoring, analysis and policy research.

Keep this section concise and readable.

EXPLORE APIx SECTION:

Create a grid of simple government-style information cards.

Cards:

1. Airfare Price Index

   "Track daily movements in domestic airfare prices."

2. Route Intelligence

   "Explore airfare movements across major city-pair routes."

3. Price Trends

   "Analyse daily, weekly and monthly airfare trends."

4. Backtesting

   "Examine historical performance of the Airfare Price Index."

5. CPI Benchmark

   "Compare APIx with the official Airfare component of CPI."

6. Data Explorer

   "Explore cleaned airfare observations and statistical records."

Each card should have:

- simple icon

- title

- one short description

- "Explore →" action

Do not overcrowd cards.

DATA SOURCES SECTION:

Create a section titled:

"Data & Statistical Sources"

Show three clean source cards:

DGCA

"Passenger traffic and route-level aviation statistics used to establish route importance and weights."

Airline & OTA Data

"Observed airfare quotations collected from airline and online travel platforms."

MoSPI CPI

"Official Consumer Price Index data used as a statistical benchmark where applicable."

Add a "View Data Sources" button.

IMPORTANT:

Clearly distinguish official source data from APIx-generated analytical results.

KEY FEATURES SECTION:

Create a clean section titled:

"Platform Features"

Use 5–6 compact feature blocks:

- High-frequency airfare monitoring

- Route-wise analysis

- Passenger-weighted index construction

- Historical backtesting

- Statistical data quality checks

- Interactive visualisation

Keep this section informational, not dashboard-like.

LATEST INSIGHTS SECTION:

Create a small preview area, inspired by the "Key Highlights" concept of government statistical portals.

Show only 3 insight cards:

- Latest Airfare Index movement

- Route with the largest fare movement

- Latest data update

These should be concise preview cards with:

"View details →"

Do NOT put a large collection of charts here.

METHODOLOGY PREVIEW:

Create a simple section:

"How APIx Works"

Show a horizontal 4-step process:

1. Collect

   Airfare observations

2. Clean

   Validate and standardise data

3. Weight

   Apply route importance using passenger traffic

4. Calculate

   Generate the Airfare Price Index

Add:

"View Methodology →"

The methodology page will contain the full statistical explanation; this homepage section is only a visual introduction.

AI ASSISTANCE:

Add a small persistent floating button:

"✦ Ask APIx"

The button should look like a government portal utility, not an AI marketing element.

It should later allow users to ask questions about APIx data, routes, trends and statistical indicators.

FEEDBACK:

Add a subtle floating:

"Feedback"

button.

It should remain accessible without interfering with page content.

The interface should be designed from the beginning to support multiple Indian languages.

Do not rely on automatic AI translation for statistical terminology. Design the UI so controlled translations can be added later.

FOOTER:

Create an official government-style footer containing:

- Government of India

- Ministry of Statistics and Programme Implementation

- APIx

- About

- Methodology

- Data Sources

- Privacy

- Accessibility

- Terms of Use

- Contact

- Feedback

Include social/official-link placeholders where appropriate.

VISUAL STYLE:

- Government-grade

- Professional

- clean

- restrained

- highly readable

- generous whitespace

- strong blue/navy as the primary government-style colour family

- white/light neutral backgrounds

- subtle secondary colours

- thin borders

- moderate shadows

- consistent iconography

- excellent typography hierarchy

Do NOT use:

- excessive gradients

- neon colours

- glassmorphism

- glowing cards

- huge KPI dashboards

- excessive animations

- cryptocurrency/fintech styling

- futuristic sci-fi visuals

- excessive rounded cards

- clutter

RESPONSIVENESS:

The page must be fully responsive for:

- desktop

- tablet

- mobile

ACCESSIBILITY:

Include:

- strong colour contrast

- keyboard-friendly navigation

- readable font sizes

- visible focus states

- accessible buttons

- language support

- dark/light mode

- screen-reader-friendly structure

The homepage should feel like an official national statistical information portal that could realistically be presented to MoSPI, RBI and government officials while still looking modern and polished.
